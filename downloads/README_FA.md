# پوشه دانلود MATINEX

فایل‌های قابل دانلودی که مالک آن‌ها هستیم یا مجوز توزیع و میزبانی‌شان را داریم، در این پوشه قرار می‌گیرند.

## مسیر دانلود در سایت

- نمونه آزمایشی: `/downloads/MATINEX-DEMO.txt`
- برای هر محصول، مسیر نسبی فایل را در پنل مدیریت وارد کنید؛ مانند `/downloads/sample.zip`.
- مسیر فقط از پوشه `downloads` پذیرفته می‌شود.

## محدودیت مهم

GitHub Pages برای میزبانی فایل‌های بزرگ بازی و فایل‌های تجاری مناسب نیست و محدودیت حجم/ترافیک دارد. این پوشه فقط برای فایل‌های کوچک و آزمایشی یا فایل‌های مجاز کم‌حجم است. برای بازی‌های بزرگ باید بعداً فضای ذخیره‌سازی ابری/سرور دانلود با دسترسی امن، کنترل پهنای باند و مجوز توزیع راه‌اندازی شود.

فایل بازی‌های تجاری، کدها و اشتراک‌ها را بدون اجازه صاحب حق نشر یا تأمین‌کننده مجاز بارگذاری نکنید.
